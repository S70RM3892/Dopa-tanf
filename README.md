# 超ドーパミン英単語帳

京大工学部情報学科・現役合格のための英単語アプリ。
**分散学習 × 想起練習 × 変動報酬 × 就寝ガード** の4本柱で作ってある。依存ライブラリなし、`index.html` を開けば動く。

## 使い方

- **ローカル**: `index.html` をブラウザで開く（サーバ不要）。
- **スマホで使う**: GitHub の Settings → Pages → Branch を選んで公開し、そのURLをホーム画面に追加。
- 記録はブラウザの localStorage に保存される。claude.ai のアーティファクト版では claude.ai アカウントに同期する。消える前に「設定 → バックアップ → 書き出す」で控えを取れ。

## 収録語（364語・例文と訳はすべてオリジナル）

| デッキ | 語数 | 狙い |
|---|---:|---|
| 多義語 | 82 | 京大和訳の生命線。address＝「取り組む」のような文脈依存の訳語 |
| 評論語 | 80 | 評論頻出の抽象名詞・形容詞 |
| 評論動詞 | 86 | attribute A to B など構文ごと |
| 英作文表現 | 60 | 和文英訳・自由英作文で「書ける」形にする |
| 情報・科学 | 56 | 情報学科志望向け。2025年の自由英作文のテーマはAI |
| マイ単語 | 任意 | 設定から自分の単語帳の語を追加（タブ区切り／カンマ区切り） |

各語に「京大ポイント」（和訳の罠・構文・語源・英作文での使い方）が付く。

## 出題形式（同じ語でも毎回変わる）

| 形式 | 中身 | 京大のどこに効くか |
|---|---|---|
| 想起 英→日 | 単語を見て意味を思い出してから開く。自己採点4段階 | 語彙全般 |
| 和訳 | 例文の下線部を文脈で訳す | 英文和訳（下線部和訳） |
| 英作文 | 日本語訳を見て、空所の英語を頭文字ヒントだけで打つ（自動採点） | 和文英訳・自由英作文 |
| 4択 | 意味を4つから即答（速いとボーナス） | 初回定着 |

## 設計と根拠

| 仕組み | 実装 | 根拠 |
|---|---|---|
| 想起練習＋分散学習 | SM-2系スケジューラ。学習ステップ 1分→10分→1日、以後は易しさ係数で間隔を伸ばす | 10の学習法のうち「有用度：高」はこの2つだけ（[Dunlosky et al., 2013](https://www.psychologicalscience.org/news/releases/which-study-strategies-make-the-grade.html)）。思い出せた後も繰り返し想起させると保持が大きく伸びる（[Karpicke & Roediger, 2008](https://source.washu.edu/2008/02/practicing-information-retrieval-is-key-to-memory-retention/)） |
| 試験日に合わせた間隔上限 | 復習間隔の上限を「試験までの残り日数の15%」にする | 最適な間隔は試験までの期間の約20%（数週間先）〜5%（1年先）（[Cepeda et al., 2008](https://www.evullab.org/pdf/CepedaVulRohrerWixtedPashler-PS-2008.pdf)）。分散効果のメタ分析（[Cepeda et al., 2006](https://pubmed.ncbi.nlm.nih.gov/16719566/)） |
| 変動報酬 | 正解の10%でクリティカル（XP×2）、2%でJACKPOT（×5）。7〜13問ごとに宝箱。コンボで効果音の音程が上がり、10コンボでFEVER（×1.5） | ドーパミン神経は予測できない報酬に強く反応する（報酬予測誤差, [Schultz et al., 1997](https://pubmed.ncbi.nlm.nih.gov/9054347/)）。好奇心・報酬期待は中脳ドーパミン系と海馬の連携を通じて記憶を強める（[Gruber et al., 2014](https://pmc.ncbi.nlm.nih.gov/articles/PMC4252494)） |
| 賞金首 | 4回以上忘れた語に正解すると+30XP、間隔7日以上まで育てたら撃破+150XP | 苦手語を避ける動機を、狙う動機に変える |
| 就寝ガード | 就寝60分前から夜モード（演出・音・新規オフ、青を抜いた琥珀色、今日の語だけ復習）。就寝〜起床は「寝ろ。」画面でロック（3秒長押しで10分だけ解除、回数は記録される） | 13〜18歳の推奨睡眠は8〜10時間（[AASM, Paruthi et al., 2016](https://www.sciencedaily.com/releases/2016/06/160613122419.htm)）。就寝前の発光画面は寝つきを遅らせ翌朝の覚醒度を下げる（[Chang et al., 2015](https://pubmed.ncbi.nlm.nih.gov/25535358/)） |
| 朝の再学習ボーナス | 起床から3時間は昨夜触った語を優先して出し、XP×1.5 | 学習と再学習の間に睡眠を挟むと練習量が約半分で済み、6か月後も保持が良かった（[Mazza et al., 2016](https://www.sciencedaily.com/releases/2016/08/160822083446.htm)） |
| 京大英語向けの出題 | 和訳モード（下線部）と英作文モード（産出） | 京大英語は英文和訳・和文英訳・自由英作文が柱（[study-search.jp](https://study-search.jp/columns/296)、[UP-EDU 京大英語解説 2025](https://up-edu.com/blog/wp-content/uploads/tsuwamono-way/english/tsuwamono-english_20251010.pdf)） |

試験日は初期値 2027-02-25（国公立前期日程の例年の開始日）。**募集要項・受験票の日付に必ず直すこと。**

## ファイル構成

```
index.html              画面とCSS（<!--page--> 〜 <!--/page--> がアーティファクト版の本体）
app.js                  ロジック全部（スケジューラ・報酬・就寝ガード・保存/同期）
words/*.js              単語データ。1行 = [見出し, 品詞, 意味, 他の意味, 例文, 例文中の対象語, 例文の訳, 京大ポイント]
tools/validate-words.mjs  単語データの検証（8要素・対象語が例文に1回だけ出る・文字数など）
```

単語を足したら検証を通す:

```sh
node tools/validate-words.mjs
```
