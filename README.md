# 超ドーパミン英単語帳 — DOPAMINE LAB

京大工学部情報学科・現役合格のための、英単語の**実験ノート**。
出題は **英→日** と **日→英** の4択だけ。答えるたびに「記録計」があなたのドーパミン応答を方眼紙に描いていく。
依存ライブラリなし、`index.html` を開けば動く。

## 中核の仕組み: 予測を裏切れ

- 各試行の前に、モデルがあなたの**予測正答率 p̂** を出す（画面右下の青鉛筆「予測 31%」）。
- 正答すると **DA = 100 × (1 − p̂)** が入る。忘れかけていた語、まだ自信のない語を当てるほど大きい。
- 誤答は予測誤差 δ = −p̂。記録計の針が沈み、連続正答が途切れる。「知らない」を押せば連続は切れない。
- 根拠:
  - 難しいが成功した想起ほど記憶が強まる（想起努力仮説: [Pyc & Rawson, 2009](https://core.ac.uk/download/357306317.pdf)）。
  - ドーパミン神経は予想外の報酬に強く反応する（報酬予測誤差: [Schultz et al., 1997](https://pubmed.ncbi.nlm.nih.gov/9054347/)）。
  - 得点式はこの考え方を借りたもの。結果画面のラスタ図は**模式図**で、脳の実測ではない。

- **昇任**: 累積DAで階級が上がり、昇任すると縦書きの**辞令**に判が押される。階級は京大の「回生」と研究職のキャリアに沿って進む（受験生 → 合格者 → 1回生 … 博士（情報学）→ 助教 … 教授 → ノーベル賞）。
- **今日のプロトコル**: 次の3項目がそろうと ＋300 DA。
  - 試行数 n ≥ 目標
  - 正答率 ≥ 85%（目安: [Wilson et al., 2019](https://pmc.ncbi.nlm.nih.gov/articles/PMC6831579)）
  - 平均反応時間 ≤ 2.5 s

## 学習の土台

- **自動判定**: 自己採点はない。正誤と反応時間から評価を決め、SM-2系のスケジューラに渡す。
- **復習間隔の上限**: 試験までの残り日数の15%で頭打ちにする（[Cepeda et al., 2008](https://www.evullab.org/pdf/CepedaVulRohrerWixtedPashler-PS-2008.pdf)）。
- **選択肢**: 同じ刺激セット・同じ品詞から、紛らわしいが正解ではない語を選ぶ（[Little et al., 2012](https://www.psychologicalscience.org/journals/psychological-science/0956797612443370/)）。
  - 意味欄には英語を入れない（検証スクリプトで強制）ので、答えが選択肢に漏れない。
  - 「正解が2つ」を防ぐため、次の語は誤答にしない:
    - 意味の語句が重なる語
    - 注釈で「＝」「≒」「同義」とされた語
    - `words/synonyms.js` の近義語の組
- **新出語**: 解説より先に出題する（[Kornell et al., 2009](https://pubmed.ncbi.nlm.nih.gov/19586265/)）。正誤表はその場で出す（[Butler & Roediger, 2008](https://doi.org/10.3758/MC.36.3.604); [Grimaldi & Karpicke, 2012](https://learninglab.psych.purdue.edu/downloads/2012/2012_Grimaldi_Karpicke_MC.pdf)）。
- **新出語の量**: 直近の正答率が高ければ新出を増やし、低ければ既習で立て直す。
- **ΣR**: 各語の想起可能性 R を単純な指数型の忘却モデルで推定した合計（忘却曲線の追試: [Murre & Dros, 2015](https://doi.org/10.1371/journal.pone.0120644)）。

## 睡眠

- **減光期（就寝60分前〜）**: 青を抜いた暗室の安全光の配色になる。音・演出・時間制限・新出を止め、今日触った語だけ確認する。
- **暗期（就寝〜起床）**: ロックする。3秒長押しで10分だけ点灯できるが、回数は記録に残る。
- **暗期遵守ボーナス**: 暗期を破らずに朝を迎えると ＋200 DA。
- **明期開始から3時間**: 昨夜の語から出し、DA ×1.5（[Mazza et al., 2016](https://www.sciencedaily.com/releases/2016/08/160822083446.htm)）。
- **根拠**:
  - 13〜18歳の推奨睡眠は8〜10時間（[AASM, 2016](https://www.sciencedaily.com/releases/2016/06/160613122419.htm)）。
  - 睡眠中の再活性化で記憶が強まる（[Rasch et al., 2007](https://doi.org/10.1126/science.1138581)）。
  - 就寝前の発光画面は寝つきを遅らせる（[Chang et al., 2015](https://pubmed.ncbi.nlm.nih.gov/25535358/)）。

| 動詞 | 331 | 構文（型）ごと覚える |

| 熟語 | 105 | 固定表現・前置詞句 |
| マイ単語 | — | 設定から自分の単語帳の語を追加 |

- **合計**: 1,188語。難度は ①576語・②547語・③65語。
- 『鉄壁』の見出し語（3,000語超）の全部ではなく、京大の和訳・評論で差がつく難関語に絞ってある。

1行 = `[見出し, 品詞, 意味(日本語のみ), 他の意味, 例文, 例文中の対象語, 例文の訳, 注釈, 型, 語源, 難度("1"〜"3")]`。

近義語の組は `words/synonyms.js` に `["tag:見出し", "tag:見出し", "理由"]` で並べる。単語や組を足したら検証を通す:

```sh
node tools/validate-words.mjs
```

## 使い方

### GitHub Pages で公開する（スマホで使う本命）

1. 初回だけ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする。
2. 既定ブランチに push すると `.github/workflows/pages.yml` が動く。
   - 単語データの検証（`tools/validate-words.mjs`）とサイト構成の検証（`tools/check-site.mjs`）を通ったときだけ公開する。
   - 手動で動かすときは Actions タブ →「GitHub Pages」→「Run workflow」。
3. 公開先は `https://s70rm3892.github.io/Dopa-tanf/`。

### ホーム画面に追加

- **iPhone/iPad**: Safari で開き、共有ボタン →「ホーム画面に追加」。
  - Safari で開いたままだと、7日間開かなかったときに記録が消されることがある。ホーム画面のアプリはこの対象外（[WebKit](https://webkit.org/tracking-prevention/)）。
  - Safari で開いている間は、ノート画面にもこの案内が出る。
- **Android**: Chrome のメニュー →「ホーム画面に追加」または「アプリをインストール」。
- 一度開けばオフラインでも動く。電波のない電車でも続けられる。
  - オンラインのときは毎回最新版を取りにいく（`sw.js`）。

### その他

- **ローカル**: `index.html` をブラウザで開くだけで動く（オフライン機能はなし）。
- **記録の保存場所**: ブラウザの localStorage。
  - claude.ai のアーティファクト版はアカウントに同期する。
  - GitHub Pages 版は端末ごとに別。
  - 「条件 → バックアップ」で書き出し・復元して、控えを取れ。
- **試験日**: 初期値は 2027-02-25。**募集要項・受験票の日付に必ず直すこと。**
- **単語ファイルを足したとき**: `index.html` の `<script>` と `sw.js` の `CORE` の両方に足し、`node tools/check-site.mjs` を通す。
