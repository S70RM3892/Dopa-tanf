# 超ドーパミン英単語帳

京大工学部情報学科・現役合格のための英単語アプリ。
**答えて、答えて、答えまくる。** 自己採点はなし。正誤と速さを自動で判定し、その結果で復習間隔を決める。
コンボ・宝箱・ミッション・実績・ガチャ・タイムアタックで報酬を積み、就寝前は演出ゼロの夜モードで寝かせる。
依存ライブラリなし、`index.html` を開けば動く。

## 使い方

- **ローカル**: `index.html` をブラウザで開く（サーバ不要）。
- **スマホで使う**: GitHub の Settings → Pages → Branch を選んで公開し、そのURLをホーム画面に追加。
- 記録はブラウザの localStorage に保存される。claude.ai のアーティファクト版では claude.ai アカウントに同期する。消える前に「設定 → バックアップ → 書き出す」で控えを取れ。
- キーボード: `1`〜`4` で選択、`0` で「わからん」、`Space`/`Enter` で次へ、スペル問題は文字キーで入力。

## 出題（すべて自動判定）

| 形式 | 中身 | 京大のどこに効くか |
|---|---|---|
| 意味（英→日 4択） | メイン。単語を見て意味を選ぶ | 語彙全般 |
| 和訳（下線部） | 例文の下線部を、この文脈での意味で選ぶ | 英文和訳 |
| 逆引き（日→英 4択） | 日本語から英単語を選ぶ | 和文英訳 |
| スペル | 日本語訳つきの例文の空所を、文字タイル（熟語は単語タイル）で組み立てる | 和文英訳・自由英作文 |

- **判定**: 制限時間の最初の25%以内に正解で PERFECT、50%以内で GREAT、それ以降は GOOD。不正解・時間切れは MISS。
- **復習間隔への反映**: MISS は最初からやり直し、復習語の GOOD は「微妙」扱いで間隔を短めにする。PERFECT が続く語は間隔を大きく伸ばす。
- **選択肢**: 同じデッキ・同じ品詞から選び、意味が重なる語（同義語・同じ漢字を含む訳語）は外す。意味欄には英語を入れない（検証スクリプトで強制）。英語が答えのヒントになるのを防ぐため。
- **新しい単語**: 解説より先にクイズで出す。間違えた瞬間に解説（構文の「型」・例文・訳・京大ポイント、選んだ誤答の意味）を出す。
- **わからん**: 押してもコンボは切れない。当てずっぽうより正直に押して解説を読め。
- **難易度の自動調整**: 直近の正答率が高ければ新出語を増やし、低ければ復習で立て直す（85%前後が目標）。

## ドーパミン設計

- **コンボ段階**: 5で WARM UP（XP×1.2）、10で FEVER（×1.5）、25で ZONE（×2・集中線）、50で GOD MODE（×3）。背景・音程・演出が段階ごとに強まる。
- **変動報酬**:
  - 正解の10%で CRITICAL（XP×2）、2%で JACKPOT（XP×5・◆×3）。
  - 宝箱は正解ごとに抽選。20コンボごとにも必ず出て、N〜URのランクがある。
- **成長**: 京大周辺の地名で昇格していく称号、毎日の3ミッション（全クリアでSR確定の宝箱）、25の実績、ラウンドごとのS〜D評価、自己ベスト表示。
- **ガチャ**: ◆で回す。中身は称号・正解エフェクト・効果音・テーマ色の34種類で、すべて見た目だけ。提供割合は画面に明示している。
- **別モード**: 60秒タイムアタック（ミスで-3秒）、賞金首狩り（4回以上忘れた語、賞金2倍）。
- **図鑑**: 出会うまで単語は「a????」のシルエットで隠れる。定着した語はホロ加工で光る。

## 睡眠ガード

- **夜モード**: 就寝60分前から。演出・音・制限時間・新規語・ガチャ・タイムアタックを止め、今日触った語だけ復習する。画面は青を抜いた琥珀色になる。
- **ロック**: 就寝〜起床は「寝ろ。」画面で固定。3秒長押しで10分だけ解除できるが、解除回数は記録に残り、翌朝の快眠ボーナスも消える。
- **朝**:
  - ロックを破らずに朝を迎えると、快眠ボーナス（+150◆）。
  - 起床から3時間は朝の再学習として昨夜の語から出し、XP×1.5。

## ファイル構成

```
index.html                画面とCSS（<!--page--> 〜 <!--/page--> がアーティファクト版の本体）
app.js                    ロジック全部（出題・自動判定・スケジューラ・報酬・ガチャ・就寝ガード・保存/同期）
words/*.js                単語データ。1行 = [見出し, 品詞, 意味(日本語のみ), 他の意味, 例文, 例文中の対象語, 例文の訳, 京大ポイント, 型(任意)]
tools/validate-words.mjs  単語データの検証（意味欄に英語がない・対象語が例文に1回だけ出る・文字数など）
```

単語を足したら検証を通す:

```sh
node tools/validate-words.mjs
```
